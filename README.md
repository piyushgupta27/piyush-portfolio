# piyush-portfolio

Personal portfolio site for **Piyush Gupta** — Sr Engineering Manager, currently at Slice, ex-Co-founder/CPO at jumpingMinds.

Live: [piyushgupta.io](https://piyushgupta.io) *(deployment in progress)*

## Stack

- Next.js 16 + React 19
- Tailwind CSS v4 + shadcn/ui
- Framer Motion
- Geist / Geist Mono fonts
- Deployed on Vercel *(TBD)*

## Forked from

[aaaby-code/portfolio](https://github.com/aaaby-code/portfolio) — initial scaffolding by Aaabad Touk. Heavily customized: accent palette, copy voice, section structure, content. Thanks for the great starting point.

## Development

```bash
pnpm install
pnpm dev      # localhost:3000
pnpm build
```
