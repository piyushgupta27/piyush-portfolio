# Security Policy

This is a personal portfolio site. It has no user accounts, no backend data
store, and no secrets in the deployed bundle — so the attack surface is small.
Still, if you find something, please report it responsibly.

## Reporting a Vulnerability

**Please do not file public issues for security vulnerabilities.**

Report privately to:

- **Email:** piyushguptaece@gmail.com
- **Subject line:** `[portfolio security]` followed by a short description

Include where relevant:

1. **Description** of the issue
2. **Reproduction steps** (proof-of-concept, configuration, or commands)
3. **Impact** (what an attacker could achieve)
4. **Affected URL / commit**
5. **Suggested fix** (optional)

## Response

This is a side project maintained by one person, so responses are best-effort.
I aim to acknowledge reports within a week and to fix anything material on the
`main` branch as soon as practical.

## Scope

In scope: the site code in this repository and its deployed output.
Out of scope: third-party platforms (the hosting provider, npm dependencies —
report those upstream), and findings that require physical access to my devices.
